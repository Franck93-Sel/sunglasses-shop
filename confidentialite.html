Politique de Confidentialité

Site de démonstration. Cette politique est un exemple rédigé à but pédagogique/portfolio, inspiré du RGPD. Le Site ne collecte aucune donnée à des fins commerciales réelles ; les informations saisies (formulaire de contact, checkout) restent locales à votre navigateur ou transitent uniquement vers les services de démonstration (Stripe test, n8n).

1. Quelles données sont traitées ?

Dans le cadre de cette démonstration, les données suivantes peuvent être saisies par vous :

  • Panier : stocké uniquement dans le localStorage de votre navigateur (jamais envoyé à un serveur tant que vous ne validez pas la commande).
  • Formulaire de commande : nom, email, adresse postale — transmis au module de paiement de test Stripe via un workflow n8n de démonstration, pour illustrer l'envoi d'un email de confirmation.
  • Formulaire de contact : nom, email, message — traité côté client uniquement dans cette démonstration, sans envoi réel.

2. Base légale et finalité

À titre d'exemple pédagogique, la base légale retenue serait l'exécution d'une commande (article 6.1.b du RGPD) pour le formulaire de checkout, et le consentement (article 6.1.a) pour les cookies non essentiels.

3. Cookies utilisés

Le Site utilise les cookies et technologies de stockage local suivants :

NomFinalitéType

4. Durée de conservation

Les données stockées localement (panier, préférence cookies) restent dans votre navigateur jusqu'à ce que vous les supprimiez manuellement ou videz le cache de votre navigateur. Aucune donnée n'est conservée sur un serveur de production.

5. Vos droits

Conformément au RGPD, vous disposeriez, sur un site réel, d'un droit d'accès, de rectification, d'effacement et d'opposition sur vos données. Sur ce projet de démonstration, il suffit de vider le localStorage de votre navigateur pour supprimer toutes les données stockées, ou de nous contacter via le formulaire de contact.
